# Вопросы для двоих — мини-приложение Telegram для пар

Пара, застрявшая в споре, по очереди задаёт друг другу вопросы:
свои, из библиотеки (мягкие / игривые / глубокие) или подсказанные ИИ.
ИИ знает «сторону» каждого партнёра, которую тот написал наедине, но не раскрывает её.
После ответа партнёр оценивает вопрос (❤️ / 👍 / 👎), и приложение показывает,
какие тона и типы вопросов нравятся каждому.

## Быстрый запуск (демо в браузере)

```bash
npm install
npm start
# открыть http://localhost:3000, переключать «Аня / Боря» в верхней панели
```

## Запуск на своём компьютере (для пробы)

Нужен Node.js 22+. Создать файл `.env` с `BOT_TOKEN=...` и выполнить:

```bash
npm install
npm run local
```

Скрипт откроет бесплатный временный HTTPS-туннель Cloudflare, запустит сервер и поставит кнопку «Играть» в чате с ботом.
Бот работает, пока окно терминала открыто и компьютер включён. Адрес туннеля меняется при каждом запуске, кнопка обновляется сама.

## Запуск на Render (бесплатно)

1. **База данных.** Зарегистрироваться на [neon.tech](https://neon.tech) (бесплатно), создать проект,
   скопировать строку подключения (начинается с `postgresql://`).
2. **Сервер.** Зайти на [render.com](https://render.com) через GitHub → **New → Blueprint** →
   выбрать репозиторий `readme-game`. Render прочитает `render.yaml` и попросит значения:
   - `BOT_TOKEN` — токен от @BotFather;
   - `DATABASE_URL` — строка из Neon;
   - `ANTHROPIC_API_KEY` — можно оставить пустым, тогда ИИ берёт вопросы из библиотеки.
3. Нажать **Apply** и дождаться статуса **Live** (3–5 минут).
4. Написать боту `/start`. Появится кнопка «Открыть игру» и кнопка «Играть» в меню чата.

Бесплатный сервер засыпает через 15 минут без активности. Первое сообщение после сна
будит его примерно за минуту, дальше всё работает быстро. Данные хранятся в Neon и не пропадают.

## Запуск в Telegram на своём сервере

1. Создать бота у @BotFather, получить токен.
2. Развернуть сервер на HTTPS-адресе (Render, Railway, VPS и т.п.).
3. Задать переменные из `.env.example`: `BOT_TOKEN`, `WEBAPP_URL`, при желании `ANTHROPIC_API_KEY`.
4. `npm start`. Бот работает через long polling, вебхук не нужен.
5. Написать боту /start → кнопка «Открыть игру». Приглашение партнёру отправляется из приложения.

## Устройство

- `src/server.js` — Express API, проверка подписи Telegram initData, бот (grammY), уведомления.
- `src/store.js` — хранение в JSON-файле `data/db.json`.
- `src/ai.js` — подсказки вопросов через Claude API (`claude-opus-5-5`, переменная `CLAUDE_MODEL`), при отказе или ошибке — библиотека.
- `src/library.js` — 45 вопросов в трёх тонах.
- `public/` — само мини-приложение (без сборки).

Приватность: «сторона» партнёра никогда не отдаётся второму партнёру через API,
и ИИ получает инструкцию не цитировать и не пересказывать её.
